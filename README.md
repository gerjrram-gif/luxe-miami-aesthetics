# Luxe Miami Aesthetics

Static site for Luxe Miami Aesthetics, a practice taking shape. Palm Beach, 240 Royal Palm Wy, and Coral Gables, Unit 110, are addresses. Neither door is open. Not yet offering treatments. There is no public shop. A franchise is not being offered, and The Atelier is not being offered. The site root is the public folder.

The homepage follows a medspa landing rhythm — light header, full-bleed hero, perk band, treatment cards, The Atelier, a Products shelf, a standards carousel, one location, an about split, a future-studio block, waitlist, and a dark footer — written entirely for Luxe.

## Pages

| File | Role |
| --- | --- |
| `index.html` | Homepage. Guest waitlist and future-studio interest both post to the Formspree placeholder. |
| `confirmed.html` | No-JavaScript confirmation for the guest waitlist. |
| `interest.html` | No-JavaScript confirmation for a future-studio note. It is not a franchise offer. |

With JavaScript, a successful signup stays on the homepage and shows the matching confirmation. Both forms still post to `https://formspree.io/f/your-form-id` until a real Formspree id is set.
