# Luxe Miami Aesthetics

Static site for a Palm Beach office planned for 2027 and the Coral Gables flagship, coming 2028. Neither is open. Not yet offering treatments. A franchise is not being offered, and The Atelier membership is not being offered. The site root is the public folder.

The homepage follows a medspa landing rhythm — light header, full-bleed hero, perk band, treatment cards, a standards carousel, one location, an about split, a future-studio block, waitlist, and a dark footer — written entirely for Luxe.

## Pages

| File | Role |
| --- | --- |
| `index.html` | Homepage. Guest waitlist and future-studio interest both post to the Formspree placeholder. |
| `confirmed.html` | No-JavaScript confirmation for the guest waitlist. |
| `interest.html` | No-JavaScript confirmation for a future-studio note. It is not a franchise offer. |

With JavaScript, a successful signup stays on the homepage and shows the matching confirmation. Both forms still post to `https://formspree.io/f/your-form-id` until a real Formspree id is set.

## Photography

The homepage frame is the static black-and-white portrait `spa/hero-bw.jpg`. It is also the Open Graph image. `hero.mp4`, `night.mp4`, `hero-poster.jpg`, and `night-poster.jpg` stay in the repo and are not used on the hero or on Own a Luxe. The Own a Luxe band is `spa/own-palm-beach.jpg`, an original photograph made for Luxe: a quiet Palm Beach clinic exterior, cream stucco, a burgundy awning, antique-gold lanterns, and royal palms. It is a still for the future office at 240 Royal Palm Wy. It is not a photograph of that address, and it is not an asset from the reference medspa. That band is not a placeholder and does not say “Coming soon.”

They are not pictures of either address, and they are not assets from the reference medspa.

On ivory the script is velvet `#6b1e2e` and the line under it is antique gold. On the hero photograph and the velvet footer the script is ivory so it still reads.
