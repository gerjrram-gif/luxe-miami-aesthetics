# Luxe Miami Aesthetics

Static site for Luxe Miami Aesthetics, a practice taking shape. Neither door is open. Not yet offering treatments. There is no public shop. A franchise is not being offered, and The Atelier is not being offered. The site root is the public folder.

The homepage follows a medspa landing rhythm — light header, full-bleed hero, perk band, treatment cards, The Atelier, a Products shelf, a standards carousel, one location, an about split, a future-studio block, waitlist, and a dark footer — written entirely for Luxe.

## Pages

| File | Role |
| --- | --- |
| `index.html` | Homepage. Guest waitlist, future-studio interest, each shelf notify form, and the LX-06 Gratitude waitlist (`#lx-06`) send through EmailJS to info@luxemiamiaesthetics.com once `emailjs-config.js` is filled in. |
| `lx-06.html` | The same LX-06 Gratitude card and seal set waitlist, for a direct link. Interest only. Same EmailJS config. |
| `emailjs-config.js` | Public EmailJS values. `REPLACE_ME` until the dashboard ids are pasted in. |
| `confirmed.html` | Static page kept from the earlier no-JavaScript path. Forms no longer open it. |
| `interest.html` | Static page kept from the earlier no-JavaScript path. It is not a franchise offer. Forms no longer open it. |

With JavaScript, a successful signup stays on the page. The guest waitlist and the LX-06 waitlist play a short sequence — Received, Sealed, On the list — only after EmailJS accepts the note, then show the matching confirmation. If the request fails or takes longer than 12 seconds, the form stays up, the ritual does not play, and the button reads Try again. A return in the same session, or reduced motion, shows that confirmation at once. A shelf notify note fades in under a short gold line. The future-studio note still swaps straight to its confirmation. Sending needs JavaScript and a filled-in `window.LUXE_EMAILJS` block in `emailjs-config.js` (public key, service id, template id). Until those say something other than `REPLACE_ME`, a submit does not leave the form and does not play the ritual. The notify template should deliver to info@luxemiamiaesthetics.com, with an auto-reply linked in the EmailJS dashboard. The public key is meant to be public. Without JavaScript, the note is not sent; write to info@luxemiamiaesthetics.com.
